# mustShip site

Одностраничный статический сайт mustShip для GitHub Pages.

## Стоимость

- GitHub Pages: бесплатно для публичного репозитория.
- Домен: не нужен.
- Внешние API: нет.
- Аналитика: нет.
- Формы: нет.
- Контакт: MustShip.gushinets@gmail.com.

## Публикация

Сайт публикуется из ветки `main` из корня репозитория через GitHub Pages.

Ожидаемый адрес:
https://gushinets.github.io/mustship-site/

## Важно

Никакие платные функции GitHub для этой страницы не нужны.
Не подключать домен или платные сервисы без отдельного решения.
