# mustShip site

Одностраничный статический сайт mustShip: услуги, проекты, команда и контакты. Адаптивная вёрстка, SVG-иллюстрации, локальные шрифты, описания проектов в диалогах и копирование email. Сборка и внешние API не нужны.

Раздел «Что делаем» обновлён 23 октября 2026: пять услуг из согласованного макета, крупные тексты и самостоятельные карандашные рисунки, чередующиеся сверху и снизу. Сетка перестраивается с пяти колонок на три; до 960 px карточки идут по одной по центру, шириной до 420 px. Описания остаются HTML-текстом. `assets/service-*-study.webp` — отдельные экспорты из согласованной сгенерированной концепции с удалённой бумажной подложкой; это условные иллюстрации услуг, не снимки продуктов. `assets/services-approved-title.webp` содержит только рукописные буквы, доступное название раздела сохранено в HTML. Подчёркивание повторяет восходящий мазок из макета через SVG-маску и однотонный CSS-цвет #107038, без растровых примесей. Новых библиотек и сетевых запросов не добавлено.

Сайт: [gushinets.github.io/mustship-site](https://gushinets.github.io/mustship-site/).

## Запуск

Из корня репозитория:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Открыть http://127.0.0.1:4173/.

## Проверка

Проверка файлов и основных ссылок без зависимостей:

```powershell
python tests/site-smoke.py
```

При работающем сервере и установленном Playwright CLI:

```powershell
playwright-cli -s=mustship-reference open http://127.0.0.1:4173/
playwright-cli -s=mustship-reference run-code --filename=check.cjs
```

Проверяет диалоги, возврат фокуса, якоря, копирование email, контраст, области нажатия и адаптивность на ширинах 320–1440 px. Скриншоты сохраняются в `output/playwright/`.

## Публикация и материалы

GitHub Pages публикует корень ветки `main`. Все пути к ресурсам относительные, поэтому сайт работает по адресу репозитория.

После изменения `styles.css` обновите `?v=` в `index.html` на первые 12 символов SHA256 файла. Это обновляет кэш CSS на телефонах; `tests/site-smoke.py` проверяет версию.

Шрифты Neucha, Nunito и Pangolin находятся в `assets/` вместе с лицензиями. `assets/logo.jpg` — предоставленный пользователем логотип; исходная картинка сохранена без изменений. `assets/artwork.png` — сгенерированный по референсу макет: CSS использует его фотографии и фактуру уголка бумаги. Четыре карандашные иллюстрации процесса сгенерированы встроенным imagegen и сохранены в `assets/process-*-pencil.webp` с прозрачным фоном. Промпты — в `docs/imagegen/process-pencil-prompts.md`. Остальные надписи реализованы текстом, иконки и рисунки — в SVG, мини-интерфейсы проектов — в HTML/CSS.

Контакт: MustShip.gushinets@gmail.com. Платные сервисы, аналитика и внешние API не подключены. `docs/` содержит документы предыдущей версии дизайна.

Миниатюра «Хозблок 3D» в карточке «Модели и расчёты» — условный SVG-эскиз интерфейса в общем стиле кейсов. Он показывает объёмный хозблок с навесом, автомобиль и габарит 6 × 8 м по демонстрационной модели. Это иллюстрация, не снимок интерфейса и не инженерный чертёж.

Первый экран обновлён 22 октября 2026 по согласованному макету: подпись под логотипом, рукописный заголовок, единая иллюстрация разработки, центрированные преимущества и карточка Live Translator. На планшете рисунок расположен справа; на телефоне — рядом с заключительным абзацем перед кнопками. Тексты перенесены из согласованной версии без редакторских изменений.

`assets/hero-approved-title.jpg`, `hero-approved-art.jpg` и `hero-approved-realized.jpg` — чистые экспорты согласованных SVG-компонентов в браузере из сгенерированной концепции, без поля рецензирования и маркеров. Новая генерация при переносе не использовалась. Рисунок разработки условный; `assets/live-translator.png` — исходный экран реального проекта. Ссылка «Посмотреть в работе» открывает https://livetranslator.anytoolai.store/ в отдельной вкладке. Кнопки обсуждения ведут к контактам, ссылки проектов — к разделу портфолио. Панель согласования и её заглушки в сайт не включены.
