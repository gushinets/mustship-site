# mustShip site

Одностраничный статический сайт для GitHub Pages.

## Стоимость

- GitHub Pages: бесплатно для публичного репозитория.
- Домен: не нужен.
- Внешние API: нет.
- Аналитика: нет.
- Формы: нет.
- Единственный контакт: style.gushinets@gmail.com.

## Публикация через GitHub Pages

1. Репозиторий должен быть Public для бесплатного GitHub Pages.
2. Откройте Settings → Pages.
3. В Build and deployment выберите:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
4. Нажмите Save.
5. После публикации сайт будет доступен по адресу вида:
   https://gushinets.github.io/mustship-site/

## Важно

Никакие платные функции GitHub для этой страницы не нужны.
Не подключать домен или платные сервисы без отдельного решения.
